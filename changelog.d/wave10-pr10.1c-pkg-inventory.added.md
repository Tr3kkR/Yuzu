- **New read-only `pkg_inventory` agent plugin — package-manager identity and Homebrew package inventory (Linux and macOS; Windows follows in a separate PR).** `managers` reports which package managers are present on the host and their manager-level configuration facts (Linux: `dpkg`, `apt`, `rpm`, `dnf`, `pacman`, `apk` tool presence, the dpkg architecture, and repository-configuration file and line counts; macOS: the Homebrew prefix layout over both `/opt/homebrew` and `/usr/local` with tap, formula and cask counts). `packages` lists the macOS Homebrew formulae and casks by name, version and kind; on Linux it reports `unsupported` because `installed_apps` already owns the Linux package roster. Both actions are pure filesystem reads with no subprocess (no `brew`, `dpkg` or `apt` is ever run), use the `Inventory` securable, and cover machine scope only: per-user package stores are out of scope. A failed or partial read reports a constrained status with a token instead of an empty result.
