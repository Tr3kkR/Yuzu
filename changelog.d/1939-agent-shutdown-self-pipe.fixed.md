- Agent shutdown is now handled off the signal handler via a self-pipe: the handler writes a single byte and a dedicated watcher thread runs the teardown. Previously the handler called `Agent::stop()` inline — taking mutexes, joining threads, allocating and logging in a signal context — and a signal delivered to a thread that `stop()` joins was a self-join, which threw out of a `noexcept` function and aborted the agent on `SIGTERM`. A second `SIGINT`/`SIGTERM` now escalates to an immediate exit, so an operator whose graceful stop is wedged is no longer forced to `SIGKILL`. If the watcher cannot start (thread or pipe exhaustion) the agent leaves `SIGINT`/`SIGTERM` at their default disposition rather than installing a handler it cannot service, so a signal is never silently swallowed.
