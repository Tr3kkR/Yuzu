- privacy_permissions plugin: per-app sensitive-permission grant visibility (camera, microphone, location, full-disk-access equivalents), read-only and off until an operator enables it with `PUT /api/v1/plugin-config/privacy_permissions/kill-switch {"enabled":true}` (`PluginConfig:Write`). Dispatch needs `Forensics:Read` with `AdminOrApproval` and names exactly one device. It reads one machine per request: Windows is measured on one non-MDM host (each user profile's CapabilityAccessManager ConsentStore plus the HKLM mirror), macOS is expected to read `denied` without Full Disk Access (the system and per-user TCC.db, read immutably in-process), and Linux reads only the agent's own session (xdg-desktop-portal), normally `unavailable` under the shipped service.
