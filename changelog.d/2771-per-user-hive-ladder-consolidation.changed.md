- **One implementation of per-user registry access.** `installed_apps`, `license_scan` and `tar` each carried their own copy of the profile-enumeration and hive-mounting logic; all three now use the shared one. Two consequences are visible to operators: `installed_apps.list_per_user` reports an unresolvable profile name as `-` instead of substituting the user's SID, and it now surfaces the hive-unload failures and missing-privilege conditions it previously discarded. Per-user application data for logged-out users is also readable on hardened installs for the first time, because that path now enables the privileges it always needed.
