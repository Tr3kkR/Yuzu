- **ADR-0031 — presentation, core and engines become separate binaries** (co-located in one container today, independently deployable by construction). Core owns the API — auth, RBAC, audit, confinement, the engine-capability registry; presentation is a transport-and-render adapter that reaches the domain only through that API, which makes ADR-1005's "no UI-only capabilities" claim structural rather than review-enforced. Engines become **headless capability providers**: no UI, no machine surface of their own. This supersedes the 2c topology's D2/D3 (engine on its own VM with its own GUI; two browser origins), voids F-10 ("no machine consumer") — closing the gap that left agentic workers unable to read a single vulnerability finding — and largely obviates F-5/INV-7, since confinement is enforced once, in core, for every consumer.
