- **`scripts/ci/check-governance-ledger.py`** — an author-side linter for a `governance.d/` run-ledger fragment that previews the self-consistency problems a strict reviewer flags, so a ledger converges in fewer review rounds. It builds a finding's live view as the field-wise merge SKILL.md mandates (ordered by `recorded_at` as a true instant; list fields replace wholesale; the five attestation fields row-scoped and exempt; a present-but-unparseable `recorded_at` is reported rather than silently sorted as legacy, since it can otherwise hide a genuine severity escalation) and checks, per row, that every row carrying ANY field `#2619` introduced (not just `schema_version`/`recorded_at` — a genuinely legacy row carries none of them) restates the eight fields SKILL.md mandates on every row even when sparse (`schema_version`, `run_id`, `finding_id`, `recorded_by`, `recorded_at`, `pass_ordinal`, `reviewed_at_sha`, `disposition`), plus `severity_native` frozen against the finding's first row, per-row `adjudicated_by`↔`adjudication_rationale` pairing, and per-row `pass_ordinal`/`run_id` value validation (`pass_ordinal` determines merge order itself, so a bad value on a losing tied row must be caught before it silently vanishes; a mid-history wrong `run_id` a later row restates correctly must still fire). On the merged view it checks: `severity_mapped` not weaker than the facts' derived floor band, with an empty-impact non-`NICE` claim excused only by a `policy_floor` citing a closed source (never a fabricated string); `epistemic_status`/`provenance`/`classification` required and non-null on a non-legacy finding (unlike `impact`/`exposure`, which explicitly tolerate a null fact set); a `wording` finding never carrying `I7`; the Gate-7 park constraint; single-value non-empty `reporter`; and enum/type hygiene for `disposition` (must always be a non-empty string; its closed-enum half is a later, `#2643`-era-plus convention), `epistemic_status`, `provenance`, `classification`, `schema_version`, `pass_ordinal`, and `independent_reporters` (excluding booleans). Only the eight per-row-mandatory fields, the required-content-presence check, and `disposition`'s closed-enum half are exempt on a genuinely legacy row (carrying none of the fields `#2619` introduced) — the content-shape enums' VALUE validity still applies, since those are general contracts, not append-machinery fields. It is deliberately ADVISORY, not a blocking corpus gate — the `/governance` skill runs it on the current run's fragment as a Gate-8 pre-push step (`--files "$LEDGER"`, fail-closed), and only its self-test runs in CI. Diff-scoped discovery fails closed on a bad base ref rather than silently reporting an empty scope.
