- **`scripts/ci/check-governance-ledger.py`** — an author-side linter for a `governance.d/` run-ledger fragment that previews the self-consistency problems a strict reviewer flags, so a ledger converges in fewer review rounds. It builds a finding's live view as the field-wise merge SKILL.md mandates (ordered by `recorded_at` as a true instant; a value that parses but carries no timezone offset — a bare date, or a naive datetime — is not an unambiguous instant and is treated the same as an unparseable value, not silently assumed to be UTC, since it can otherwise hide a genuine severity escalation the same way a wholly-unparseable value can; list fields replace wholesale; the five attestation fields row-scoped and exempt) and checks, per row, that every row carrying ANY field `#2619` introduced restates the eight fields SKILL.md mandates on every row even when sparse (`schema_version`, `run_id`, `finding_id`, `recorded_by`, `recorded_at`, `pass_ordinal`, `reviewed_at_sha`, `disposition`) — with all eight now having their VALUE, not merely their presence, validated per row (a bad value on an early row a later valid row "corrects" is a permanently-recorded defect nothing else would flag): `schema_version`/`pass_ordinal` non-bool integers, `reviewed_at_sha` a non-empty non-whitespace string, `disposition` likewise, and `recorded_by` nullable only on the row that first raises the finding (a non-null value on any row must still be a genuine non-empty non-whitespace string). Plus `severity_native` frozen against the finding's first row and per-row `adjudicated_by`↔`adjudication_rationale` pairing. On the merged view it checks: `severity_mapped` not weaker than the facts' derived floor band, with an empty-impact non-`NICE` claim excused only by a `policy_floor` citing a closed source; `epistemic_status`/`provenance`/`classification` required and non-null on a non-legacy finding (a legitimate later correction of an earlier omission still resolves via the merge); a `wording` finding never carrying `I7`; the Gate-7 park constraint; single-value non-empty `reporter`; and enum/type hygiene for `disposition`'s closed-enum half, `epistemic_status`, `provenance`, `classification`, and `independent_reporters` (excluding booleans). Only the eight per-row-mandatory fields, the required-content-presence check, and `disposition`'s closed-enum half are exempt on a genuinely legacy row (carrying none of the fields `#2619` introduced). It is deliberately ADVISORY, not a blocking corpus gate — the `/governance` skill runs it on the current run's fragment as a Gate-8 pre-push step (`--files "$LEDGER"`, fail-closed), and only its self-test runs in CI. Diff-scoped discovery fails closed on a bad base ref rather than silently reporting an empty scope.
