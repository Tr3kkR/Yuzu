- **Breaking - gateway heartbeat admission is bound to the connection of the session's Subscribe stream (gateway restart required).** The Erlang gateway admits an agent `Heartbeat` only on the HTTP/2 connection that opened its session's `Subscribe` stream; any other heartbeat gets `NOT_FOUND` and is counted (`yuzu_gw_heartbeat_rejected_total{reason}`, `yuzu_gw_heartbeat_session_mismatch_total{event="security"}`), not forwarded. Agents must reach the gateway directly or via L4 / TLS passthrough; HTTP/2-terminating proxies are unsupported. A rejected agent re-registers (logic from v0.13.0), but released v0.13.0 and v0.14.0-rc6 agents wedge in their reconnect path with default settings (#2182, fixed by #5183, in no release yet) and recover only with `--no-auto-update`; v0.12.0 never recovers (older versions not tested). Upgrade agents first (a build with the fix, once released), then the gateway; restart an agent that stays rejected. `/readyz` now reports `sessions_index`. Refs #1197, #3869.
