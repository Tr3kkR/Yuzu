- **`cert_scan` plugin: SSL/TLS certificate and private-key discovery.** Walks every local user's home directory (auto-discovered per-OS, or an operator-supplied `paths` override) for certificate material, certificate signing requests, and private keys that escaped managed custody. Never emits raw key material or certificate bytes — only structural metadata for certificates and a classification label for keys/containers. Severity: CRITICAL for an unencrypted private key, HIGH for an encrypted key or PKCS#12/JKS container, MEDIUM for an expired/self-signed/unverifiable certificate, LOW for a valid certificate, INFO for a CSR.
