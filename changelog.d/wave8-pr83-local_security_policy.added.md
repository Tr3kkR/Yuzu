- **`local_security_policy` plugin (new, read-only, `Security`).** `password_policy`, `lockout_policy`, `audit_policy` (Windows: legacy `[Event Audit]` categories only) and `sudoers` (risk Medium; Linux/macOS). Linux reads login.defs/pwquality/faillock/PAM/audit.rules/sudoers files; macOS runs `pwpolicy -getaccountpolicies` (rung 2) and reads audit_control/sudoers (the root LaunchDaemon can read sudoers; an unprivileged run reports it `unreadable`); Windows runs `secedit /export` (rung 2), staging the whole SECURITYPOLICY export in an owner-only `agent.data_dir` directory removed on return and swept after a crash. A failed read is `unreadable` with a reason token, never an empty result.
