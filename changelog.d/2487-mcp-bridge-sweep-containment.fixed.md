- MCP progress bridge: a transient allocation or lock failure inside the periodic bridge sweep can no longer abort the whole server process (#2487). The sweep runs on the server's maintenance thread, where an escaped exception is fatal, and its teardown path copied an execution id and built an audit string outside any containment - reachable in production whenever a session with an in-flight streamed request expires. The copy is gone (the id is borrowed, not duplicated), the audit detail no longer allocates at the call site, each teardown step is contained independently, and the maintenance tick guards the bridge sweep and MCP session collection separately so a failure in one cannot suppress the other. New counters `yuzu_mcp_bridge_teardown_incomplete_total` (by stage), `yuzu_mcp_bridge_sweep_tick_failures_total` and `yuzu_mcp_session_gc_tick_failures_total` surface any teardown that could not finish; all are pre-seeded to zero and any nonzero value warrants an alert.
