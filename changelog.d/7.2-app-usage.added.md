- New `app_usage` plugin: read-only `summary`/`last_used`/`foreground` views over TAR's new `usage` fold — a machine-scope, per-executable run-count/duration inventory derived entirely from process start/stop events, with no pid, command line, or user name ever surfaced (per-executable user identity is folded into a `COUNT(DISTINCT user)` only). Gated behind a new `Forensics` securable (Administrator by default, admin-or-approval, single-target). A daily-sync source centralises a trailing-30-day per-executable window to the server (`app_usage_store`), readable via `GET /api/v1/forensics/agents/{id}/app-usage` and the `get_agent_app_usage` MCP tool; the store is the sixth member of the agent-decommission cascade, erased by a whole-device `DELETE /api/v1/sle/agents/{id}` under the scoped `Decommission:Delete` securable (see `docs/user-manual/app-usage.md`).
