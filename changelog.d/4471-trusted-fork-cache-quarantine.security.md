- Trusted-fork CI dispatches (`fork-dynamic-review.yml`, `trusted-fork-ci.yml` → `ci.yml`) are confined to a throwaway per-PR `trusted-fork/pr-<N>` branch, fail-closed in `ci.yml`'s `trusted_inputs` step and the review workflow, so approved fork code can never write the GitHub Actions cache scope that `dev`/`main`/PR runs restore from; the wrapper purges that scope after the run. CodeQL's `actions/cache-poisoning/poisonable-step` query, whose model cannot see the confinement and re-fired on every new preflight step, is excluded with an in-repo checkout-ref sweep in its place (#4471).
