- **`certificates` plugin reads the macOS login keychain without a shell.** The console user's login-keychain enumeration (`list`/`details` with `store=login`/`all`) now runs `security find-certificate` under its `launchctl asuser`/`sudo -u` session hop as a pre-split argv vector through the bounded subprocess runner — the `/bin/sh -c` wrapper is gone. The shell's only remaining job was `~user` tilde expansion, now performed in-process via the same `getpwnam_r` directory-services lookup the shell used, so the path read is identical (relocated and network home directories included). This promotes the leg from rung 3 (governed-shell exception) to rung 2 under ADR-3002 and retires the plugin's last shell-payload subprocess (#3406).
