- **`software_actions` and `license_scan` (Linux) migrated off raw `popen`/`_popen` shell-outs onto the governed acquisition ladder.** `software_actions`'s `list_upgradable`/`installed_count` now acquire via the bounded argv runner on Linux/macOS (rung 2) and, on Windows, `installed_count` reads the Uninstall registry key natively (rung 1, zero subprocesses) instead of a `powershell -Command` shell-out. `license_scan`'s Linux `pkg_metadata`/`entitlement_certs` surfaces move to the same bounded argv runner; the Linux legs of its `list` and `surfaces` actions are deliberately demoted from SUPPORTED to CONSTRAINED to honestly reflect their existing limitations (declared-licence classification only for `pkg_metadata`, no lapse detection; `entitlement_certs`' authoritative expiry still depends on the `openssl` CLI being present). Windows `list_upgradable` now parses winget's fixed-width table by column position rather than by runs of whitespace: rows whose name or identifier filled its column were previously mis-read, reporting the package source in place of the available version.
