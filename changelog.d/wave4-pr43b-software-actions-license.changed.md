- **`software_actions` and `license_scan` (Linux) migrated off raw `popen`/`_popen` shell-outs onto the governed acquisition ladder.** `software_actions`'s `list_upgradable`/`installed_count` now acquire via the bounded argv runner on Linux/macOS (rung 2) and, on Windows, `installed_count` reads the Uninstall registry key natively (rung 1, zero subprocesses) instead of a `powershell -Command` shell-out. `license_scan`'s Linux `pkg_metadata`/`entitlement_certs` surfaces move to the same bounded argv runner; their capability declaration is deliberately demoted from SUPPORTED to CONSTRAINED to honestly reflect their existing limitations (declared-licence classification only for `pkg_metadata`, no lapse detection; `entitlement_certs`' authoritative expiry still depends on the `openssl` CLI being present).
