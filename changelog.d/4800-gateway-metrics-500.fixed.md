- **The gateway's `:9568/metrics` endpoint no longer returns HTTP 500 on every scrape (#4707).** Five metric HELP strings added with gateway cluster formation (HA WS-4, #4555) contained an em dash. `prometheus_text_format` crashed with `badarg` on each one, so every scrape failed with a bare inets 500 and no gateway metrics reached Prometheus, including the connected-agent count. The HELP text is now plain ASCII, and a new eunit test renders the real metrics registry, so a non-ASCII HELP string now fails the fast gate.
