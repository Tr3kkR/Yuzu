- **New `browser_inventory` agent plugin — Chromium-family browser and profile inventory (the per-profile extension listing follows in a separate PR).** `browsers` reports which Chromium-family browsers (Chrome, Edge, …) are installed; `profiles` reports each browser's profile directories and display names, read from its `Local State` file. On Linux both actions are real reads over a per-user home-directory walk; macOS and Windows report a planned placeholder until their own follow-up work. Never emits an account identifier, browsing history, cookies or bookmarks in any row, on any OS leg. Ships DEFAULT-OFF behind the server-side plugin kill switch and gates at the `Forensics` securable, admin-or-approval, single-target only — the same boundary as the existing `execution_artifacts` and `app_usage` plugins. A failed or partial read reports a constrained status with a token instead of an empty result.
