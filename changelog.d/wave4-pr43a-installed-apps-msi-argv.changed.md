- **`installed_apps` and `msi_packages` Linux/macOS collection moved off shell popen onto the bounded argv runner.** `installed_apps`'s Linux (dpkg-query/rpm/pacman/apk) and macOS (system_profiler/brew) legs, and `msi_packages`'s macOS (pkgutil) legs, now exec their tools directly through the shared, deadline-bounded subprocess runner instead of a shell (`popen()`/`/bin/sh -c`) — no shell-quoting/injection surface, and a degraded run (timeout, spawn failure, truncated output) is now logged instead of silently reading as an empty result. `list`/`query`/`list_per_user`/`product_codes` output is byte-identical to before.
