- **New read-only `runtimes` agent plugin — installed .NET and JVM runtimes (Linux; the macOS and Windows legs and the `python` action follow in separate PRs).** `dotnet` reports the .NET shared frameworks and SDKs installed under the standard dotnet roots and `jvm` reports each Java home's vendor and version from its `release` file. Every action is a pure filesystem walk with no subprocess (no `dotnet` or `java` is ever run), uses the `Inventory` securable, and is bounded per directory; a directory that cannot be read reports a constrained status with a token instead of an empty result. On macOS and Windows every action answers `status|<action>|unsupported|<os>:planned` until those legs land.
