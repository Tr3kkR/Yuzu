- **New read-only `runtimes` agent plugin — installed .NET, JVM and Python runtimes (Linux; macOS and Windows follow in separate PRs).** `dotnet` reports the .NET shared frameworks and SDKs installed under the standard dotnet roots, `jvm` reports each Java home's vendor and version from its `release` file, and `python` reports the CPython interpreters and library directories present. Every action is a pure filesystem walk with no subprocess (no `dotnet`, `java` or `python` is ever run), uses the `Inventory` securable, and is bounded per directory; a directory that cannot be read reports a constrained status with a token instead of an empty result. On macOS and Windows every action answers `status|<action>|unsupported|<os>:planned` until those legs land.
