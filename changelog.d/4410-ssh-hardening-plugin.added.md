- **SSH server hardening audit plugin (`ssh_hardening`, Linux-only).** Audits `/etc/ssh/sshd_config` (and every file it `Include`s) against the Mozilla "Modern" OpenSSH baseline, checking that `KexAlgorithms`, `Ciphers` and `MACs` are restricted to the approved algorithm list and that every `HostKey` directive references an approved key type (ed25519, rsa, ecdsa). Audit-only — never modifies `sshd_config`. Read-only, `Security:Read`, no approval gate.
