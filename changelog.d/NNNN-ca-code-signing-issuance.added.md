- Added `POST /api/v1/ca/issue-code-signing`, a `Security:Write`-gated REST route for code-signing leaf issuance via the internal CA. Operators hold the private key and submit a CSR; the server signs and returns the leaf plus the issuer chain. Usage is hard-pinned to `codeSigning` (never `clientAuth`/`serverAuth`) and the subject is the operator's validated label — never an agent identity — so this cannot collide with the agent-enrollment namespace the general `POST /api/v1/ca/issue` route remains deferred over.
