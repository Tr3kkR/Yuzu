- **TAR DNS capture source reports an honest `unsupported` status on macOS.** A 2026-07-19 spike (roadmap 4.9) confirmed no userspace mechanism can enumerate the DNS resolver cache on modern macOS — `dscacheutil -cachedump` is defunct, `scutil --dns` returns configuration rather than cached entries, and the mDNSResponder cache is dumpable only as root to the redacted system log. The `dns` capture source's macOS row now reports `unsupported` (previously `planned` via the dead `dscacheutil` mechanism), so the TAR compatibility surface reflects reality instead of a plan that can never land.
