- **`quarantine` plugin no longer shells out.** All 43 spawn sites (15 Windows `netsh`, 22 Linux `iptables`, 6 macOS `pfctl`) move from raw `popen`/`_popen` onto the bounded argv runner — Linux and macOS calls are sudo-wrapped in the canonical argv form the installer's sudoers grants already expect. The macOS `pfctl` reload strategy (one atomic full-ruleset load with `set skip on lo0`, which fixed a prior connectivity-loss incident) is unchanged — this migration touches only the spawn mechanism, not the ruleset design. Output parsing for status/whitelist reads moves to a new pure `quarantine_parsers.hpp`.
