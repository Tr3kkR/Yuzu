- `/governance` Gate 7 now has an explicit disposition step for non-blocking findings, ordered after validity, severity derivation and policy floors so it can never read as a waiver: a fix that opens an independently reviewable surface (new authority, persistent state or ownership lifecycle, external I/O, public contract, or a new dependency/process/thread) splits out, while completing an existing mandatory seam folds; and separability is judged against the acceptance envelope fixed before the findings arrived, not against whether the change still feels worthwhile. A valid finding that is neither fixed nor filed is recorded as `not-planned` with a named non-author adjudicator — `rejected` stays reserved for findings that are false or disproven. The post-run section's "typically produces 8-15 deferred follow-up items" expectation is removed as a quota that made filing the default
