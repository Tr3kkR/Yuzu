- CSRF-gated dashboard actions no longer fail with `403 cross-origin POST refused` behind a reverse proxy that rewrites `Host`. Declare the external origin with `--csrf-trusted-origin https://yuzu.example` (repeatable, comma-separated permitted, `YUZU_CSRF_TRUSTED_ORIGIN`); a scheme-qualified entry is matched on scheme as well as host, which also stops an `http://` Origin satisfying an `https://` deployment. `X-Forwarded-Host` is deliberately never consulted, so the trust anchor stays a config value an attacker cannot set. Leaving the flag unset keeps the previous same-host-only behaviour (#2537)
