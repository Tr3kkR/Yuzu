- Guardian service guards (`service-running` / `service-stopped`) now arm on macOS via launchd: a `service-status-change` Guard in a deployed cross-platform Baseline begins detecting service run-state drift on Mac endpoints at agent upgrade, reported as `drift.detected` with `platform=macos` through a 30-second `launchctl print` poll plus a kqueue process-exit overlay (~0 ms stop detection).
