- **macOS `wifi connected` reports the live connection again.** The action shelled out to the private `airport -I` helper, which Apple removed in macOS 14 (Sonoma), so it silently reported "Not connected" on every modern Mac even while associated. It now reads the association directly via CoreWLAN (RSSI, channel, security, BSSID, interface). Where macOS withholds the SSID/BSSID behind Location Services (as it does for a background daemon), the connection is still reported honestly with an `<ssid-withheld>` marker rather than a false "Not connected".
