- **Network configuration now reads adapters, IP addresses, DNS servers, proxy settings and the ARP table through native OS interfaces.** Linux uses rtnetlink (RTM_GETLINK/RTM_GETADDR/RTM_GETROUTE) and `/proc/net/arp`; macOS uses getifaddrs, a PF_ROUTE sysctl and SCDynamicStore, keeping the existing SIOCGIFMEDIA link-speed read. The ARP/neighbour table is reported on Linux and macOS for the first time. macOS proxy detection now covers every network service rather than Wi-Fi alone, and macOS DNS reporting now includes supplemental per-service resolvers (VPN split-DNS and secondary interfaces) alongside the primary, de-duplicated. macOS IPv4 netmasks are reported as CIDR prefix lengths instead of raw hex to match the Linux output, which also corrects point-to-point interfaces that previously reported their peer address in the netmask field. The Linux DNS-cache read remains `resolvectl`, now invoked as a direct argv command instead of through a shell.
