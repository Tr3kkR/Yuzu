- **Network configuration now reads adapters, IP addresses, DNS servers, proxy settings and the ARP table through native OS interfaces.** Linux uses rtnetlink (RTM_GETLINK/RTM_GETADDR/RTM_GETROUTE) and `/proc/net/arp`; macOS uses getifaddrs, a PF_ROUTE sysctl and SCDynamicStore, keeping the existing SIOCGIFMEDIA link-speed read. The ARP/neighbour table is reported on Linux and macOS for the first time, macOS proxy detection now covers every network service rather than Wi-Fi alone, and macOS IPv4 netmasks are reported as prefix lengths to match the Linux output. The Linux DNS-cache read remains `resolvectl`, now invoked as a direct argv command instead of through a shell.
