- `script_exec` now executes commands and scripts through the shared bounded subprocess runner with per-line incremental output streaming preserved (16 MiB streamed-output cap retained), replacing its private `CreateProcessA`/`fork`+`execvpe` paths; timeout, cancellation, and output-cap behaviour now come from the runner contract, and the plugin's grandfathered raw-spawn lexical-gate entry is removed. Environment behaviour is unchanged on both platforms: POSIX children continue to receive the same curated `PATH`/`HOME`/`USER`/`LANG`/`LC_ALL`/`TERM`/`TZ` allow-list, and Windows children continue to inherit the full parent environment. First unit tests for `script_exec` land alongside.
