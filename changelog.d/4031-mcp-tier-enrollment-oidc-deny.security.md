- **MCP tokens can no longer reach `Enrollment`/`OidcConfig` reads at any tier (readonly, operator, or supervised).** `tier_allows()` (`mcp_policy.hpp`) previously checked only the operation (`Read`), never the securable type, so an MCP token could reach the #4031 REST v1 enrollment auto-approve-rules, pending-agents, and OIDC-config routes despite the #520 invariant that MCP tokens must never administer the server itself (settings, users, TLS, OIDC) — the same reason those three routes deliberately have no MCP tool twin. `Directory` is unaffected — it has real MCP twins by design.
