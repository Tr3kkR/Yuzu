- **`scripts/ci/ensure-postgres.sh` path 1: fail instead of falling back on a manifest-vouched Postgres fault.** A manifest-vouched `psql` (`YUZU_CI_PSQL`, exported by `deploy/windows/Assert-Toolchain.ps1 -ExportCiEnv`) has already proven the exact `psql.exe`/cluster pair earlier in the same job, so a `SELECT 1` failure against it — for agent 0/the base cluster as well as any further agent — is now retried briefly and then fails the job outright, instead of silently falling back onto the shared agent-0 cluster (the #2094 cross-job contention the per-agent split exists to avoid). The pre-existing warn-and-fall-back behaviour for an *unprovisioned* box (a `PATH`-sourced or absent `psql`) is unchanged.
