- **Engine-principal stream re-validation no longer hammers Postgres.** Each held-open MCP/SSE stream re-checks its credential every pump tick; for engine principals that check read through to Postgres every time, which under a connection-pool brownout turned into a self-amplifying stall that starved ordinary requests, not just streaming. Liveness re-checks are now served from a 60-second cache, invalidated the moment a principal is revoked or its owner changes. Fresh authorization decisions — session creation and on-behalf-of target checks — still read through on every call, so revoking an engine principal stops new sessions immediately. The server also warns at startup when `--max-sse-streams` is set far above `--postgres-pool-size`.
