- **Two sources of Windows CI test flakiness root-caused and fixed.** `yuzu_agent_tests` and `yuzu_server_tests` now share a Catch2 main that calls `hard_exit()` immediately after a successful run on Windows only (#3507 AC1), protecting the passing case from a rare post-summary teardown-thread crash that was being misclassified as a test failure. Separately, loopback HTTP tests asserting a pre-routing rejection (413/415/403) now tolerate a Windows-only httplib behavior where the server's early rejection response can be lost to a connection reset before the client reads it (#2757): each fixture's own pre-routing handler gains a "rejection witness" counter, and the shared `yuzu::test::expect_pre_routing_rejection` helper accepts the Windows fallback only when both an RST-class error occurred *and* the witness proves the fixture's own handler actually rejected the request, not merely that the server was alive.
