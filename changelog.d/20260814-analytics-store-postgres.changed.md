- **`AnalyticsEventStore` moved from a local SQLite outbox to the PostgreSQL substrate** (ADR-0049). Ingest and reads keep the same fail-soft/degrade-distinguishable behavior operators already see; the drain-to-sink pass is now single-sweeper fleet-wide instead of per-process. The legacy `analytics.db` is not migrated — any events buffered but not yet drained at the moment of a cutover are lost; a boot log records the store's Postgres configuration on every start, and new events buffer normally from first boot.
