- Agent shutdown no longer takes up to 13.5s. The trigger-engine worker loops polled a stop flag with `sleep_for()` — and on Linux/macOS the registry watcher, which has no work to do at all, slept a full 5 seconds per iteration — so each worker took up to 5s to notice a stop request and `stop()` joins them serially. They now wait on a condition variable and wake immediately. Core teardown drops from ~8s to ~1s, which matters because Docker's default 10s stop grace was killing containerised agents mid-teardown.
