- **`discovery` subnet scan no longer spawns a process per host.** A `/24` sweep previously launched up to 254 `ping` processes; it now probes hosts over a single unprivileged ICMP socket. The ARP table is read natively on every platform — `GetIpNetTable2` on Windows, `/proc/net/arp` on Linux, and the kernel routing table on macOS — instead of parsing `arp` command output. On Linux hosts where `net.ipv4.ping_group_range` does not admit the agent, the scan now returns its ARP-derived hosts and reports the result as constrained and partial, instead of reporting an empty network.
