- **`registry.get_user_value` now works for logged-in users.** It previously assumed every profile lived at `C:\Users\<username>\NTUSER.DAT` and always attempted an offline hive mount, which fails when the target user is already logged in (the common case) — the action worked only for users who were logged out. It now resolves the profile via `ProfileList`, reads the live hive when the user is logged in, and falls back to an offline mount otherwise. It also accepts an explicit `sid` parameter as an alternative to `username`.
