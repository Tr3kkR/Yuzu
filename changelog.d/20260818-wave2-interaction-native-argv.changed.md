- **`interaction` plugin's last two raw shell-outs are gone.** The Windows `input`/`survey` actions (PowerShell InputBox/WinForms dialogs) move from `_popen` onto the bounded argv runner — the script itself is still interpreted by PowerShell (unchanged, deepest-interpreter rung), only the outer spawn mechanism changes. The Linux `zenity` dialog paths, already on the runner, drop their vestigial nested-shell `__RC=$?` exit-code protocol in favor of reading the runner's real exit code directly.
