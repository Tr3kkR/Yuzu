The prose-ownership split is also stated where agents read it rather than only where it is declared: `docs-writer`'s Gate 2 brief covers in-code comments and log/error strings the diff changes, it is now the only reviewer that files wording findings, and a *missing* required doc is a truth finding rather than a wording observation capped at NICE — with "required" defined against the routed-concern table and the deep-dive checks instead of left to judgement.
