## Resource Ledger ADDENDUM (Gate 8, cpp-safety: policy-floor omission corrected; supersedes "no new callback context / temp path" for the TEST files)

Production code (spark_file.cpp, spark_mechanism.hpp, spark_heartbeat.hpp) still acquires NO new resource; the new state remains value members guarded by `mu_` plus one relaxed atomic. Test-only, all inside the `#ifdef _WIN32` region of tests/unit/test_spark_mechanism.cpp:
- `PfStallLogger` (PF-11/PF-12): owner = the test's stack frame (non-copyable RAII, declared BEFORE `mech`). Acquisition = ctor swaps the process default spdlog logger for a logger `pf_stall` holding the previous sinks plus a sleeping sink (shared_ptr `sink_`, `prev_`). Release = dtor `set_default_logger(prev_)` on every path (incl. a failed REQUIRE / exception); ordering: `mech` is destroyed first (its dtor calls stop(), which joins the worker), so the worker never logs through a destroyed logger. Transfer: none. Failure cleanup: RAII. KNOWN residual: the dtor does not unregister the name `pf_stall`, so spdlog's registry retains the logger and sink (with a dangling by-ref `on_hit`) until process exit; nothing logs to that name (Gate 8 cpp-safety: `spdlog::drop("pf_stall")` fix pending).
- The sink's `on_hit` closure: a callback context holding by-reference captures of test locals (`passes_at_stall`, `inert_at_stall`, `mech`, counters), stored in the sink; safe because every capture is declared before `mech` and no matching line can be logged after `mech` has joined; the sink sleeps (400/300 ms) while holding its own mutex (blocks only other loggers, bounded).
- One `ScratchDir` (temp directory via `yuzu::test::unique_temp_path` with the `yuzu_test_` prefix, RAII) per new test; hook lambdas (`pass_fail_hook`, `attach_fail_hook`, emit/fault/established sinks) capture by reference locals declared before `mech`; `GetProcessTimes(GetCurrentProcess())` uses a pseudo-handle (no handle acquired).
